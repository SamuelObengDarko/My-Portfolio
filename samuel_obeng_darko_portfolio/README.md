# Samuel Obeng Darko — Portfolio starter

A responsive personal portfolio made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colours, responsive styles
- `script.js` — mobile navigation, current year, copy-email interaction

## Run locally
Open `index.html` in your browser. For a smoother editing workflow, open the folder in VS Code and use the Live Server extension.

## Before publishing
1. Add a professional headshot and replace the monogram graphic if you want a photo.
2. Confirm your internship dates and add the actual responsibilities at TGTS Africa and Sacrefilms Multimedia.
3. Add GitHub links, live demos, screenshots, and concrete outcomes to project cards where available.
4. Confirm that all listed tools reflect your current skill level.
5. Add a downloadable CV only after you have prepared a current version.
6. Review contact details and remove any information you do not want public.

The academic performance project is described as a proposal/in development, not as a completed project. The work-history entries intentionally include prompts where exact duties were not confirmed.
